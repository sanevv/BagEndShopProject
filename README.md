# BAGEND 세미 프로젝트


## 1. 프로젝트 소개

BAGEND는 팀 단위로 진행한 웹 서비스 프로젝트입니다. 
브랜드 정체성이 확실하고 직관적인 UI를 지닌 업사이클링 패션 브랜드 누깍(NUKAK)을 모티브로 하여, 실제 웹사이트 운영에 필요한 다양한 쇼핑 기능을 구현하고자 했으며, 
사용자에게는 간결하고 직관적인 쇼핑 경험을 제공하고, 
관리자에게는 상품, 회원, 주문 관리 등을 효율적으로 관리할 수 있는 시스템을 구축하는 것을 목표로 하였습니다.

- 개발 기간: 2025.06 ~ 2025.07 (1개월)
- 개발 인원: 5명
- 프로젝트 유형: 팀 프로젝트

---

## 2. 담당 역할
본 프로젝트에서 아래 기능들을 담당하여 구현했습니다.

- 사이트 공통 레이아웃 구성
- 메인페이지 메인 슬라이드 배너 API 호출 및 렌더링
- 상품 상세 정보 조회
- 리뷰 CRUD
- 관리자 댓글 CRUD

---

## 3. 기술 스택
- Backend: Java, Spring Boot, Lombok
- Data Access: JDBC (Plain JDBC, DAO Pattern)
- Database: Oracle
- Build Tool: Gradle
- Infra: AWS EC2 (Ubuntu), Docker

### 3-1 기술 선택 배경
- 본 프로젝트는 Spring Boot 애플리케이션의 기본 구조와 데이터 접근 흐름에 대한 이해를 목적으로 진행했습니다.
- ORM(JPA) 도입 이전 단계에서 순수 JDBC 기반 DAO 패턴을 적용하여 SQL 실행 과정과 자원 관리 방식에 대한 이해를 높이고자 했습니다.

---

## 4. 주요 기능 설명

### 4-1 상품 상세페이지 조회
- 상품 ID를 기준으로 상품 상세 정보를 조회하는 기능 구현
  
### 4-2 리뷰 CRUD
- 상품별 리뷰 조회, 등록, 수정, 삭제 기능 구현
- 인증된 사용자만 리뷰 작성 가능하도록 처리

### 4-3 관리자 댓글 CRUD
- 리뷰에 대한 관리자 댓글 CRUD 기능 구현
- 관리자 권한을 가진 사용자만 댓글을 등록, 수정, 삭제할 수 있도록 인증 및 권한 체크 로직을 분리하여 적용
- 리뷰 조회 시 관리자 댓글 정보를 함께 조회하여 화면에 노출되도록 구현
